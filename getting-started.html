Getting started

Install Slidey, make a first deck, and present it. About 5 minutes.

1. Install Slidey

Slidey isn't in Obsidian's community plugin list yet. Install it with BRAT, a helper plugin that installs plugins straight from GitHub and keeps them up to date.

  1. In Obsidian, open Settings → Community plugins. If Restricted mode is on, turn it off.
  2. Click Browse, search for BRAT (“Obsidian42 - BRAT”), then click Install and Enable.
  3. Open the command palette (Ctrl+P) and run BRAT: Add a beta plugin for testing.
  4. Paste Venari-Hunt/slidey and confirm.
  5. Back in Settings → Community plugins, make sure Slidey is switched on.

BRAT checks for new Slidey releases when Obsidian starts and installs them for you.

The first time Slidey runs, it downloads its slide engine (about 12 MB) from the matching GitHub release. That happens once per version.

2. Make your first deck

  1. Create a new note.
  2. Type /slides and pick Make this note slides: every heading is a slide. This adds slides: headings to the note's properties.
  3. Write a few headings with some text under each: 
    # My first deck

## Hello
Some text on the second slide.

## Goodbye
- One point
- Another point

3. Preview it

Click the slides icon in the left ribbon, or run Show slide preview from the command palette (running it again closes the preview). The deck opens beside your note and updates as you type. Moving your cursor in the note jumps the preview to that slide.

4. Present it

Run Present slides (fullscreen). Use → / ←, Page Down / Page Up, Space, or your USB clicker to move through the slides. Press Esc to leave. Give the command a hotkey in Settings → Hotkeys if you present often.
