Slide menu (/)

Type / in a slide note to add anything to a slide, without remembering the syntax.

How to use it

  1. On an empty line (or after a space), type /. A list of slide actions opens.
  2. Keep typing to narrow it down: /two finds the two-column layout, /bg finds the background options, /notes finds speaker notes.
  3. Press Enter (or click) to insert it. The cursor lands where you type next. After /bg, for example, you type the picture's file name.

In notes that aren't slides yet

In an ordinary note, type /slides to turn it into a slide note. Pick one of the three ways to split it. Slidey sets the slides: property for you.

With other / menus

If you also use Slash Commander or Obsidian's own slash commands, both keep working:

  • In ordinary notes, a bare / opens your usual menu. Slidey only shows up after /sl….
  • In slide notes, a bare / opens the slide menu. When nothing in it matches what you type (for example /table), your usual menu shows instead.

To turn the slide menu off, go to Settings → Slidey → Slide menu (/).
