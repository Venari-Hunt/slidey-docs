Deck defaults

These apply to every deck unless its properties say otherwise:

  • Default slide theme and Default highlight theme: the base reveal.js theme and the code highlighting colors.
  • Transition style and Transition speed: how one slide changes to the next.
  • Center content: center slide content vertically.
  • Controls, Progress bar, Slide numbers: on-screen extras.
  • Default horizontal / vertical slide separator: change --- and -- for separators mode.
  • Math engine: KaTeX or MathJax for formulas.
  • Presentation plugins: chalkboard, elapsed time bar, laser pointer, menu, overview.

Preview server

The preview runs on a small web server inside Obsidian, on your computer only.

  • Automatically start the preview server: start it when Obsidian starts.
  • Server port (default 3000) and Server host: change the port if another program already uses 3000.

Backup and restore

Export settings saves all Slidey settings, including your styles and presets, to a file. Import settings loads them back. Do this before reinstalling the plugin.
