FAQ & troubleshooting

The preview is black or empty

  1. Click the slides icon in the ribbon to reload the preview for the current note.
  2. Run Stop slide preview server, then Start slide preview server.
  3. Still black? Restart Obsidian. Since 0.15.1, a stuck PDF export can no longer cause this, so a restart clears anything left over.

How do I update Slidey?

If you installed it with BRAT (see Getting started), updates arrive by themselves when Obsidian starts. To update right away, run BRAT: Check for updates to all beta plugins and UPDATE. Obsidian's own “Check for updates” button doesn't see Slidey, because it isn't in the community plugin list yet.

“Unable to start server. Is 3000 already in use?”

Another program uses port 3000. Change Settings → Slidey → Server port to something else, like 3100, then restart Obsidian.

My font doesn't show

The font must be installed on your computer, and the name must match exactly, including spaces and capitals: font="Open Sans". Slidey doesn't download fonts from the web.

My picture doesn't show

  • Check the file name, including its extension (.jpg, .png).
  • For names with spaces, use a link: %% bg=[[My photo.png]] %%.
  • The picture must be in your vault, or be a full web address.

A slide's label is red with a “?”

The layout, style or preset name is misspelled or doesn't exist. Check it against Layouts & styles, or pick it from the / slide menu so it's always spelled right.

My usual / menu stopped showing

In slide notes, a bare / opens the slide menu. Type what you want (/table) and your usual menu comes back when nothing in the slide menu matches. To turn the slide menu off, go to Settings → Slidey → Slide menu (/).

My clicker does nothing

  • Make sure the slide preview (or present mode) is open.
  • Test the keys it sends: open a text note and press the clicker. If it types nothing, check its USB receiver or batteries.

Where do I report a problem?

On GitHub: Venari-Hunt/slidey issues.
